Buffer C
====

* 100 mM Tris-HCl, 300 mM NaCl, 6 M urea, 500 mM imidazole 
* Buffer C only needed in cold room and need to be pre-cooled in cold room

* Empty bottle 
* Distilled H2O
* Magnetic stirrer
* :ref:`1M Tris-HCl <tris-hcl>`
